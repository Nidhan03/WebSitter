Elderly Mode

Bigger, clearer, and harder to get scammed on.

  • 🔍
    Zoom everything, proportionally Text, buttons, icons, and images all scale up together, like zooming the whole page — nothing shrinks or gets left behind.
  • 🚫
    Ad & tracker blocking Known ad and tracking domains are blocked at the network level before they ever load, using Chrome's built-in request filtering.
  • ⚠️
    Scam language detection Scans page text for urgency and scam phrases ("act now", "your account has been suspended") and shows a dismissible warning banner.
  • 💬
    Tap-to-explain Hover any button or link to reveal a "?" badge — click it for an instant, plain-language explanation of what it actually does, powered by Groq.
👶

Kid-Safe Mode

Filters what shouldn't reach a kid's screen.

  • 🖼️
    On-device image blurring Every image is scanned by an NSFW-detection model running entirely in your browser — nothing is uploaded, no API key needed. Flagged images blur automatically with click-to-reveal.
  • 🔗
    Risky link warnings Clicking a link to a known-unsafe domain shows a warning first, so a stray click doesn't land somewhere it shouldn't.
  • 🤬
    Toxic comment filtering Comments on the page are scored for toxicity via Google's Perspective API and blurred if flagged, with click-to-reveal.

API keys for tap-to-explain and comment filtering live in config.js on your machine — never synced or sent anywhere except directly to Groq / Google's Perspective API.
