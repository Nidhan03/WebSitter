      About WebSitter

      The web wasn't built with everyone in mind — WebSitter is our attempt to fix that, one page at a time.

      It's a browser extension built for the people the web is often hardest on: elderly and low-digital-literacy users navigating confusing pages and scam attempts, and kids who can stumble into content or conversations they shouldn't. It offers two completely independent modes, applied automatically the moment you visit any site — no per-site setup, no accounts, nothing to remember to turn on. Everything runs either fully on-device or through minimal, purpose-specific API calls, and your settings live in your own browser profile.

      👴 Elderly Mode, in depth

      Bigger buttons & text

      Rather than selectively resizing individual elements (which tends to break layouts or leave some things, like inline images, awkwardly small) Elderly Mode applies a uniform CSS zoom to the entire page — the same effect as zooming in a browser, but automatic and adjustable from four preset levels (Small to Extra Large). Text, buttons, icons, and images all scale together, so proportions and layout stay intact.

      Ad & tracker blocking

      Known ad and tracking domains are blocked using Chrome's native declarativeNetRequest API — requests are refused at the network level, before they ever reach the page, rather than being hidden after the fact with CSS. This is both faster and harder for a page to work around. You can add your own domains to block on top of the bundled list, right from this settings page.

      Scam language detection

      WebSitter scans visible page text for common urgency and scam phrasing — things like "act now," "your account has been suspended," or "you have won" — entirely client-side, with no data leaving your browser. A dismissible warning banner appears the moment a match is found, so you get a heads-up before entering any personal information.

      Tap-to-explain & read-aloud

      A small ❓ badge appears when you hover any button or link. Clicking it sends just that element's label to Groq's language model, which returns a one-sentence, plain-language explanation of what it actually does — cached so the same button never costs a repeat request. Separately, highlighting any paragraph reveals a 🔊 Listen button that reads the selected text aloud using your browser's own built-in speech synthesis — no network call, no API key, completely free.

      👶 Kid-Safe Mode, in depth

      On-device image blurring

      Every image on the page is classified by NSFW.js, a machine-learning model that runs entirely inside your browser using the same MobileNetV2 architecture found in many production content-moderation systems. No image is ever uploaded anywhere — the model and its weights are bundled directly into the extension. To keep things fast, classification only happens as images scroll into view, rather than scanning the entire page up front. Anything flagged gets blurred immediately, with a click to reveal.

      Risky link warnings

      Before following a link, WebSitter checks its destination against a bundled blocklist of known-unsafe domains, plus anything you've added yourself. If it matches, a confirmation prompt appears before the browser navigates anywhere — a stray click never silently lands somewhere it shouldn't.

      Toxic text filtering

      Comments, reviews, and general page text (paragraphs, list items — not just comment-shaped elements) are batched and scored for toxicity via a dedicated Groq account, kept separate from tap-to-explain so the two features never compete for the same usage quota. Anything scoring above the toxicity threshold is blurred immediately, with a click to reveal if you decide you want to see it anyway.
